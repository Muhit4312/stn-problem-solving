# STN-7 Problem Solving Assessment

A collection of 20 problem-solving solutions implemented in JavaScript as part of the STN-7 assessment.

## 📌 Overview

This repository contains solutions to 20 assigned programming problems. All solutions are implemented in a single JavaScript file using the exact function names and parameter structures specified in the assessment.

## 🛠️ Technologies Used

- JavaScript (ES6+)
- Node.js

## 🚀 How to Run

### Prerequisites

Make sure Node.js is installed on your computer.

### Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Navigate to the Project Directory

```bash
cd problem-solving
```

### Run the Solutions

```bash
node solution.js
```

**Note:** The file contains function definitions. To see output in the terminal, add test cases using `console.log()`.

## 🧪 Testing

The solutions should be tested using:

- Provided assessment examples.
- Additional valid input cases.
- Edge cases such as empty arrays, zero values, duplicate elements, and boundary conditions.

## 📝 Implementation Notes

- All 20 solutions are organized in one `solution.js` file.
- Original function names and parameter structures are preserved.
- Solutions use JavaScript built-in methods and appropriate algorithms.
- In-place problems modify the original input array when required.
- No hardcoded outputs are used.
